# 🚀 Web Infrastructure & Security Refresher

과거의 인프라/네트워크/보안/스크립트 지식을 빠르게 되살리고, 실무 감각을 복구하기 위한 리포지토리입니다.

## 📁 Repository Structure
1. `01_Linux_System_DeepDive.md` : 리눅스 핵심 명령어, 프로세스/메모리/디스크/네트워크 상태 확인
2. `02_Network_Protocol_Packet.md` : TCP/IP, HTTP/HTTPS, tcpdump/Wireshark 패킷 분석
3. `03_Web_WAS_Architecture.md` : Nginx, Tomcat 동작 구조 및 리버스 프록시 연동
4. `04_Web_Security_Attacks.md` : WAF/IPS/IDS, SQLi, XSS, File Upload 원리 및 방어
5. `05_Log_Troubleshooting.md` : Syslog, ELK, 장애 원인 분석 방법론 (502, 504 에러 등)
6. `06_Script_Regex.md` : Shell, Python을 활용한 로그 파싱 및 정규표현식(PCRE)
7. `07_Virtualization_Cloud.md` : Docker, AWS 기본 개념 리마인드
